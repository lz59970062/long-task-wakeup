    启动子 Agent¶

    一项工作能够独立描述时，可以交给子 Agent。例如检查某个模块、整理实验结果，或根据需求实现一个小功能。

    提交一次代码审查¶

    ltc agent codex --cwd "$PWD" --task "检查参数解析" -- "阅读 parser.py 和相关测试，检查空输入、非法参数和边界值，报告问题的位置、触发条件与修改建议。"

    codex 选择执行任务的子 Agent。-- 后面写它要完成的工作。把要读的文件、期望产物和判断标准写清楚，子 Agent 就可以围绕这项工作展开。

    任务提交后，LTC 会打印日志路径和回答文件路径。子 Agent 结束时，回调返回发起任务的会话。原会话读取回答、检查相关文件，再继续处理结果。

    选择子 Agent¶

    命令 执行者 版本
    ltc agent codex Codex CLI 0.7.0
    ltc agent claude Claude Code CLI 0.7.0
    ltc agent pi Pi 0.7.1 预览版

    在提交任务的环境中安装并登录对应 CLI。子 Agent 会继承该环境的配置、代理和项目路径。

    例如，在 Codex 会话中调用 Claude 做审查：

    ltc agent claude --cwd "$PWD" --task "审查数据加载" -- "检查 data_loader.py 的文件读取、批次拼接和异常处理，给出可复现的问题。"

    结果仍回到这次提交所在的 Codex 会话。回调目标由提交会话决定，执行者由 agent 后面的名称决定。

    给任务一个清楚的交接要求¶

    在提示词末尾说明希望看到的结果，例如：

    完成后列出修改的文件、执行过的测试命令和测试结果，并说明下一步需要检查的内容。

    经常重复的要求可以保存为任务模板。
